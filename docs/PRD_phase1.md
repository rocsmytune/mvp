# 机柜物料管理平台 · 阶段1 PRD

版本：v0.2　范围：物料管理与查询、机柜可视化、多角色鉴权
不在范围：BMC采集、转移单、盘点、退库流程、拖拽、利用率（字段与入口预留，不实现）

## 1. 目标与验收

| 目标 | 验收标准 |
|---|---|
| 替代 Excel 查找物料 | 输入任意整机SN/部件SN/IP，3秒内显示 机房-机柜-U位-柜主 |
| 位置可信 | 50台试点设备，抽查10台位置与实物全部一致 |
| 权限可信 | 柜主无法修改他人机柜数据（后端测试用例证明） |
| 历史数据可迁移 | 真实历史Excel可导入，无法解析的进入待整理池而非报错 |
| 试点接受度 | 20名试点用户中多数表示愿意用它代替翻Excel |

## 3. 位置模型（依据真实数据）

导出表位置由三列组成：

| 列 | 示例 | 解析结果 |
|---|---|---|
| 所属实验室 | `上海/SH-LQH-B13-B03-145R/绿区` | 城市=上海；机房编码=SH-LQH-B13-B03-145R；区域=绿区 |
| 机架号 | `B01-16` | 机柜名=B01-16（同时拆出 row=B01、col=16 供排序筛选） |
| U数 | `22-23` | u_start=22, u_end=23, u_size=2；单值如 `22` 视为1U |

- 机柜统一 **45U**，U1 在最底部（默认约定，待确认）。
- 机柜唯一键：(机房, 机柜名)。
- 区域（绿区等）属于机房属性，作为筛选维度。
- 设备类型：服务器、交换机。暂无半宽/多节点设备。

## 4. 导入规则（重点）

1. 逐行解析三列。三段全部合法 → 挂载到机柜；机柜不存在则**自动创建**（owner为空，待总管理员指派）。
2. 任一段解析失败、U位越界（<1 或 >45）、或与同柜已有设备U位重叠 → 设备进入**待整理池**，`location_raw` 保存三列原文拼接，并记录原因（`pool_reason`）。
3. 去重键优先级：`bmc_ip` > `ip_inband`。命中则更新，不命中则新增；两个IP分别命中不同设备 → 标记冲突，不自动合并。
4. 更新时：`source=manual` 的字段不被Excel覆盖，产生冲突提示。
5. 导入分三步：上传 → 预览（新增/更新/冲突/错误分色，可下载）→ 确认入库。每次导入生成 ImportBatch 与报告。
6. 可用字段仅：CPU型号、IP（带内/带外）、位置。其他列忽略，不入库。

## 6. 部件管理

- 单件管理（有SN）：主板、CPU、内存、硬盘、网卡、光模块。
- 数量管理（无SN）：线缆、风扇板等，记型号与数量。
- 每个SN记录来源 `sn_source`：import / manual / bmc(预留)。
- 同一SN出现在两台设备 → 给出冲突提示，不直接拒绝。

## 7. 非功能要求

- 所有写操作经统一服务层，自动写ChangeLog（谁、何时、字段、前后值、来源）。
- 搜索接口P95 < 500ms（1000台、数万部件规模）。
- 每日数据库备份。
- 认证模块可替换，用户主键为工号。
- 开发/测试仅使用脱敏或构造数据。
