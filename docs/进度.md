## 已完成

### 0. 项目初始化
- git 仓库（github.com:rocsmytune/mvp）
- 文档：CLAUDE.md / docs/PRD_phase1.md / docs/schema.sql

### 1. 项目骨架
- 后端：FastAPI + SQLAlchemy 2.x + Alembic；8 张表模型 + 初始迁移
  （含 `btree_gist` 扩展、U 位不重叠排除约束、3 个 CHECK 约束）
- 前端：Vite + React + TS + AntD
- docker compose：db / backend / frontend 三容器，热重载
- 冒烟测试通过，整栈 curl 验证

### 2. 本地登录 + 鉴权
- 接口：`POST /api/auth/login`、`GET /api/auth/me`
- 认证：bcrypt 密码哈希 + JWT（HS256）；业务侧统一依赖 `get_current_user`
- 权限：`permissions.py` 仅角色常量（具体校验待各写接口接入时实现）
- 种子：`backend/seed.py`（3 个构造账号）
- 前端：登录页（工号+密码，SSO 入口预留），token 存 localStorage，axios 拦截器自动附带
- 测试：6 个登录用例通过
